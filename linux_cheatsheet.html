journalctl --since "2026-03-20 08:00" --until "09:00"Exact range
journalctl -bCurrent boot only

💾 iostat — I/O & CPU Statistics

Basic usage (from sysstat package)
iostatOne-time CPU + disk report
iostat -xExtended disk stats
iostat -x 2Extended, refresh every 2 s
iostat -x 2 5Extended, 5 reports then exit
iostat -dDisk only (no CPU)
iostat -cCPU only (no disk)
iostat -hHuman-readable sizes
iostat -kOutput in KB/s
iostat -mOutput in MB/s
iostat -p sdaStats for specific device + partitions
iostat -tShow timestamp each report
iostat -y 2Omit first summary (show live only)
Key extended (-x) columns
r/s, w/sRead / write requests per second
rkB/s, wkB/sKB read / written per second
rrqm/s, wrqm/sMerged requests per second
awaitAvg wait time per request (ms)
r_await, w_awaitSeparate read / write await
aqu-sz (avgqu-sz)Avg queue length — if >1, disk is saturated
%util% time device was busy — >90% = bottleneck
svctmAvg service time (deprecated)
Related tools
iotopPer-process I/O (like top for disk)
iotop -oShow only active I/O processes
vmstat 2VM, CPU, I/O summary every 2 s
sar -d 2 5Disk activity (sysstat)
sar -u 2 5CPU utilisation (sysstat)
lsblkBlock device tree
blockdev --getsize64 /dev/sdaDevice size in bytes

🔬 strace — System Call Tracer

Attach & run
strace lsTrace all syscalls of ls
strace -p 1234Attach to running PID
strace -f cmdFollow child processes / threads
strace -ff -o out cmdEach thread to out.PID file
Filtering
strace -e trace=open,read,writeTrace specific syscalls
strace -e trace=fileFile-related syscalls
strace -e trace=networkNetwork syscalls
strace -e trace=processProcess syscalls (fork, exec…)
strace -e trace=signalSignal syscalls
strace -e trace=ipcIPC syscalls
strace -e trace=memoryMemory syscalls (mmap, brk…)
strace -e trace=descFile descriptor syscalls
Output & timing
strace -tt cmdMicrosecond timestamps
strace -T cmdTime spent in each call
strace -c cmdSummary: count & time per syscall
strace -C cmdSummary + live trace
strace -o trace.log cmdSave output to file
strace -s 256 cmdPrint up to 256 chars of strings
strace -v cmdVerbose (full struct contents)
strace -x cmdPrint non-ASCII as hex
strace -e read=3 cmdHex dump reads on fd 3
Common debug patterns
strace -e openat -p $(pgrep app)Which files is app opening?
strace -e trace=network -p 1234Network calls of running proc
strace -c -p 1234Syscall profile of live proc
strace -f -e trace=execve bash -c "cmd"Trace all execs in script
